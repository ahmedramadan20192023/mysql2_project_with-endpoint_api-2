Correct workflow in simple words (delete-user)

1. Receive the user ID → req.params.id
2. Check whether the user exists in the database
3. If a database error happens → return 500
4. If the user doesn't exist → return 404 and stop
5. If the user exists → execute the DELETE query
6. If the delete query fails → return 500
7. If no row was deleted → return an error response
8. If deletion succeeds → return 200 with success message
